Create full backup

Choose a strong, unique passphrase to protect your gateway and its saved secrets.

Use at least 12 characters, ideally several random words. Save it in your password manager separately from the backup.

Creating a backup briefly stops and restarts the gateway; active calls may be interrupted. A native save dialog asks where to put the encrypted file. Store a copy away from this computer. Losing the passphrase makes the backup unusable.

Restore full backup?

Replace this gateway's data with an encrypted full backup.

The current connections, policies, settings, audit history and stored secrets will be replaced. Create a full backup first if you need to keep them.

GateRook checks the passphrase and backup integrity before a final confirmation, then replaces data and closes. Reopen GateRook and reconnect your AI apps after recovery.

Restored plugins stay disabled until you review them; external MCP servers start on first use. Tunnels stay off. Files outside the GateRook data folder need to be linked again, and plugin runtimes may need reinstalling.

Enter the passphrase used when the backup was created. The next dialog selects the encrypted backup file. Use the same GateRook version that created it; the file must be no larger than 256 MiB.

Enter RESTORE exactly, then choose the backup to restore.
