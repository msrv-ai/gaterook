Risky combination in endpoint dev

An agent that reads untrusted text can be steered into sending private data out. This endpoint has all three ingredients; approval on http_request helps only if you read every request body.

  • Private data, present sql_query reads dev-db environment dev
  • Untrusted content, present loki_search returns log lines users wrote
  • External channel, present http_request can POST to billing-api environment stage
