      Add MCP server

      Put any MCP server behind the gateway. It runs as its own process; its tools get modes, approvals and audit.

      Lowercase letters, digits and -. It also prefixes the tool names.

      Transport

      stdio: the gateway starts a command on this computer. HTTP: it calls a URL with Streamable HTTP.

      Runs without a shell, from ~/.gaterook/mcp/ and the server name. Pin a version (@1.2.3): without one, npx can fetch new code on every start.

      HTTPS, or http://127.0.0.1 for a server on this computer.

      Variables or headers

      Values always come from Secrets, never typed here. Only these reach the process, and the agent never sees them.

      Start MCP server sentry-mcp?

      This code runs on your computer with these secrets. Nobody has verified it: it can read them and reach anything your user account can.

      Command
      npx -y @sentry/mcp-server@0.17.0
      Version
      Pinned to 0.17.0. npm checks the package integrity on every start. Not pinned npx can fetch new code on every start, with these secrets. Add @version to the package.
      Runs as
      Your user, without a shell or a sandbox, from ~/.gaterook/mcp/sentry-mcp. Not sandboxed on this system: it can read everything your account can, including GateRook's data.
      Secrets passed
      SENTRY_AUTH_TOKEN from the secret sentry-mcp/token
      Tools
      Listed after the start and Off until you add the server to an endpoint. Tools declared read only and not destructive start in Read only; other tools start in Approval. The server declares these annotations; the gateway can't verify them.
