Masked before storage

Policies replace secrets and personal data in arguments and results with ‹masked› before a call is written here. The originals are never stored, so nobody can reveal them later.

Query syntax

Type field:value and press Enter: each one becomes a filter tag. Different fields combine with and; repeat a field for or (tool:sql_query tool:logs_search); - excludes; * matches any text.

decision
allowed, approved, pending, denied, rejected, expired, error
tool
sql_query, sql_*
client
codex, claude-desktop, claude-ai, cursor, playground
endpoint
dev, incident-prod, stage-readonly
connection
dev-db, cache-redis
env
dev, stage, prod
token
codex-laptop, bridge (Claude Desktop), oauth (claude.ai)
rule
prod.sql.block_ddl (the policy rule that decided)
runbook
restart-api, compose-ps (ssh_run calls)
trace
4f2a9c (a prefix is enough)
duration
>1s, <50ms

Examples

decision:denied env:prod
What the policy stopped on prod
tool:sql_* -decision:allowed
SQL calls that needed your approval or failed
client:codex duration:>1s
Slow calls from Codex
decision:rejected decision:expired
Requests you turned down or did not answer in time
