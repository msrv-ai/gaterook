Connectors

The types of resource the gateway can reach and the tools each one brings. Add a type without rebuilding: a template, a plugin or an MCP server.

New templateSQL query, SSH runbook or OpenAPI import. No code.

How it works

Three levels of connectors. Whatever the level, every tool goes through tokens, modes, approvals and audit.

  1. 1Built-in

    SQL, MongoDB, Redis, OpenSearch, Elasticsearch, SSH, log services, Kubernetes, clouds and HTTP ship with the core. Add a connection and go.

  2. 2Templates without code

    A named SQL query, an SSH runbook or an OpenAPI file becomes a tool with typed parameters. No restart.

  3. 3Plugins and MCP servers

    A Java plugin adds a new resource type in its own plugin process; an MCP server runs as its own process. Check the signature first.

How github-mcp runs

Process, variables, logs and protocol.

Package
@modelcontextprotocol/server-github@0.6.2, pinned. npm checks its integrity hash against the signed catalog entry on every start.
Trust
The signature says which package this is, not that its code was reviewed. It runs as your user, without a sandbox: it can reach the network and the files your account can.
Process
Started by the core on the first call, stopped after 15 min without calls. Running for 2 h. A crash never stops the core.

Variables passed

HTTPS only. The file is downloaded and checked the same way.

Nothing loads before the check of the signature and the manifest (tools, hosts and commands it needs). Signed by the catalog: review and install. Unsigned: you confirm the risk first.

Add MCP server

Put any MCP server behind the gateway. It runs as its own process; its tools get modes, approvals and audit.

Lowercase letters, digits and -. It also prefixes the tool names.

Transport

stdio: the gateway starts a command on this computer. HTTP: it calls a URL with Streamable HTTP.

Runs without a shell, from ~/.gaterook/mcp/ and the server name. Pin a version (@1.2.3): without one, npx can fetch new code on every start.

HTTPS, or http://127.0.0.1 for a server on this computer.

Variables or headers

Values always come from Secrets, never typed here. Only these reach the process, and the agent never sees them.
