How it works

Connect writes one entry into the app's config, with a backup first. The app gets the tools of one endpoint and never a secret.

  1. 1We find the AI app

    Claude Desktop, Codex, Cursor and Antigravity are found by the config files they keep on this computer.

  2. 2Show what changes

    You see the exact diff of the config file, for example ~/.cursor/mcp.json, before anything is written.

  3. 3Back up, then write

    The file is copied next to itself, then one entry is added. Other MCP servers in it stay untouched.

  4. 4Disconnect removes the entry and revokes the token

    The file goes back to how it was, and the app's token stops working on its next call.

Shell List the tools from a terminal 
npx -y @modelcontextprotocol/inspector@2.12.0 --cli --config gw-inspector.json --server gaterook-dev --method tools/list

  }
