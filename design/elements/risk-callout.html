Risk callout

Warns when one endpoint mixes private data, untrusted content and a way to send data out: an agent that reads untrusted text can be steered into leaking private data. Database rows, logs and HTTP responses count as untrusted; every HTTP and SSH tool counts as a channel (fixed runbooks as a limited one). Used on endpoint detail, Endpoints (compact) and Policies.

Contained: the only way out is fixed runbooks

incident-prod reads prod data and prod logs, and SSH reaches prod-vm. SSH is a channel, but here the agent can only run two fixed runbooks with no free-text parameters, so it can't put data into it. An info alert explains the mitigation and what would break it; it never says nothing can send data out.

Contained combination in endpoint incident-prod

Private data and untrusted text meet a limited channel: SSH runs only fixed runbooks. A runbook with a free-text parameter, or any HTTP tool, would turn this into a full warning.

  • Private data, present sql_query reads prod-replica
  • Untrusted content, present logs_search on prod-logs, sql_query rows
  • External channel · limited, present ssh_run runs 2 fixed runbooks on prod-vm, no free-text parameters
