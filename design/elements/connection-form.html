From JSON Schema to fields

For designers and connector authors: how the connector's schema becomes this form.

Top-level objects
One form section each, in schema order: connection, credentials, advanced (collapsed).
title, description
The field label and the hint under the control.
required
Required fields stay plain; the others get "Optional" after the label.
enum
A select (SSL mode). Five options or fewer with descriptions become choice cards.
integer, minimum
A mono text input with inputmode="numeric", a unit affix, checked on save.
array of strings
A tag list with an add input (schema allowlist).
writeOnly, format: "password"
A gw-secret with the secret source picker. Never echoed back by the API.
Added by the gateway
Environment and safety, and Test connection: the same for every connector.
