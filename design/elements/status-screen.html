Status screen

What the window shows while the gateway core is not available: waiting for unlock, starting, failed to start (port in use, master key missing, any other reason), or stopped. It replaces the whole app (no sidebar, nothing to navigate to), says what is happening and why, and offers the one or two actions that fix it. Used on Core starting and by the desktop app whenever the core exits. Each state below sits in a preview frame; in the app the screen covers the window.

The macOS prompt may name “MCP Gateway Dev Safe Storage”. This is GateRook’s existing keychain entry; its name is kept so saved credentials stay accessible.

Failed: didn't start

Any other reason the core gives for not starting gets this card: the title says the reason in words, then the facts of the stopped card and the last log lines. The stepper shows only when the core got as far as a step; a second core on the same data folder stops at the database lock before any.
