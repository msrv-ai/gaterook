How it works

The agent never sees a secret value, only the result of the call.

  1. 1Store or reference

    Paste the value here, or point to Vault, GCP Secret Manager or AWS Secrets Manager.

  2. 2Encrypted with your master key

    AES-256-GCM, with the key in ~/.gaterook/master.keyset, outside the database.

  3. 3Decrypted only inside the connector, at call time

    The value lives in memory for one call and never leaves the connector.

  4. 4Agent gets the result, masked

    Secrets and PII in the output become ‹masked› before the agent sees it.

Connectors, three steps

Top of Connectors: three ways to add a resource type. Three steps share the row in equal columns; the Learn more link is optional and left out here.

How it works

Add a resource type without rebuilding the gateway. Every new tool still goes through tokens, policies and approvals.

  1. 1Write a template

    SQL or an HTTP call with typed parameters becomes a tool. No code, no restart.

  2. 2Install a plugin

    A Java plugin adds a new resource type with its own tools. Its card says whether it is signed.

  3. 3Add an MCP server

    Put a server you already run behind the gateway. Its tools get modes, approvals and audit like any other.

Authorization

Settings, Authorization: gw-how-it-works--vertical keeps the list inside the narrow settings column at any width.

How it works

Every AI app is tied to one endpoint and can be cut off at once.

  1. 1AI app gets a token or signs in with OAuth

    Desktop AI apps use a bearer token; claude.ai signs in with OAuth 2.1 through the tunnel.

  2. 2Token is bound to one endpoint

    A token for dev cannot call stage-readonly. Named tokens last 7 days by default; Claude Desktop and Codex get 15-minute ones on the fly.

  3. 3Policy decides allow / approval / deny

    Each call is checked against the tool's mode and the environment's limits.

  4. 4Revoke any time

    The next call with a revoked token is refused. Nothing to restart.

AI apps, collapsed

Top of AI apps after the user folded it: the title and the one-line summary stay. Open it with the chevron button.

How it works

Connect writes one entry into the AI app's config, with a backup first.

  1. 1We find the AI app

    Claude Desktop, Codex, Cursor and Antigravity are found where they keep their config.

  2. 2Show what changes in its config

    You see the exact diff, for example in ~/.codex/config.toml, before anything is written.

  3. 3Back up, then write

    The current file is copied next to it, then one entry is added. Other MCP servers stay untouched.

  4. 4Disconnect removes the entry and revokes the token

    The config goes back to how it was, and the AI app's token stops working.
