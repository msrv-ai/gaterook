Keys, avatars, client marks gw-kbd gw-avatar gw-client-mark

Small identity and hint marks. Keys show a shortcut in running text, help and the command palette. Avatars are people (approvers, users in server mode): circles. Client marks are MCP clients: rounded squares with a neutral monogram, never a vendor logo. Official marks come only from vendor press kits, after sign-off.

Keyboard keys

One kbd per key, written as text (Esc, Enter, Shift). Arrows and Return are Lucide icons with screen reader text. Inside a button use gw-btn__kbd instead.

Press ⌘K to search, Esc to close.

Move with Up arrowDown arrow, run with Enter.

Approve the open request with ⌘ShiftEnter.

Avatars

Two initials on a neutral circle, or a photo in __img. Next to a visible name the avatar is aria-hidden; alone it is role="img" with the full name. Sizes: --sm 20 (table rows, timelines), default 28, --lg 40 (account, users). People appear only in server mode (Users and roles, a server-mode preview); the desktop app has one local user, so its history says “by you” and needs no avatar.
