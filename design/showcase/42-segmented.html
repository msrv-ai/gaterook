Segmented control gw-segmented

A real radio group drawn as joined segments: Tab lands on the checked option, arrow keys move and select, the value submits with the form, no script. The main case is the tool mode Off · Read only · Approval · Bypass; Bypass runs calls without approval, including changes to data. The checked option takes its tone from data-tone (off neutral, read info, approval warning, or any tone name such as dev, stage, prod) with an edge in the tone colour, semibold text and its own icon, so the choice never rests on a tint alone. Without data-tone it is brand, for plain view switches. For a mutating tool Read only is disabled and the reason is visible next to the control and linked with aria-describedby. Not for switching views of a panel (that is gw-tabs--contained) or for more than four options (use gw-select).
