Every value a person types sits in a gw-field: a visible label above the control, a hint under it, and after a failed save an error with an icon, tied to the control with aria-describedby. Controls are native and 32px tall; literal values (hosts, ports, paths) use gw-input--mono. Mark the few optional fields "Optional" instead of starring every required one. Not for values people only read and copy (gw-copy-field) or for secrets (gw-secret); for two to four options that change behaviour use gw-segmented.
