Progress and meters gw-progress gw-meter

Progress shows how far a task has got: setup steps, a plugin upload, the core starting. The page sets the fraction on the root (style="--gw-progress: 0.42") and the ARIA values; with no estimate it is indeterminate. For a short wait in place (a button, Test connection) use a spinner instead. Meter shows an amount against a limit: calls per hour, response size, rows returned. The page compares it with its thresholds and sets data-level; the value is always written out. Neither one is a chart: compare values over time with a chart.
