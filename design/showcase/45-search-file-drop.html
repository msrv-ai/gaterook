Search and file drop gw-search gw-file-drop

Search filters a list or table as you type and is the input of the command palette: icon at the start, a clear button once it has a value, an optional key hint while empty. The placeholder is required (clear and hint key off :placeholder-shown) and the input is named with aria-label; for structured queries (decision:denied tool:sql_*) the same field sits in log-explorer. File drop uploads a plugin JAR, an OpenAPI document or a kubeconfig: a label around a transparent input type="file", so click, keyboard and a dropped file all work without script; the app sets data-state. Actions on an uploaded file (remove, replace) go outside the label: a label must not contain buttons.
