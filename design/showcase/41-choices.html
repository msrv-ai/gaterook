Checkbox, radio, switch gw-checkbox gw-radio gw-switch

The native input does the work and is stretched, transparent, over the whole choice, so the box, the label and the hint are one target at least 24px tall. Checkbox: a value saved with the form, several independent options, "select all" (indeterminate is a property, set from script: [indeterminate] in Angular). Radio: one of a few options that each need a sentence; with an icon and a description use gw-choice-card, with one word each use gw-segmented. Switch: a setting that applies at once, with no Save; never inside a form that has a Save button. Dependent options under a "select all" sit in gw-field--nested; in a table the selection column uses the box without a label (gw-table). Unavailable, with a reason: aria-disabled="true" + aria-describedby on the input (the hint says why); it looks like disabled, stays in the Tab order, and kit.js keeps it from toggling. Native disabled only when there is nothing to explain.
