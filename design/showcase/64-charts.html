Charts gw-chart gw-legend gw-sparkline

Lightweight charts in HTML, CSS and inline SVG, no library: a stacked histogram of calls over time, a horizontal bar list for top tools, a sparkline inside a stat. Data enters as unitless custom properties (style="--v: 0.42", value ÷ axis max). Every chart is role="img" with an aria-label that states the finding, and the numbers sit next to it in a visually hidden table. Series differ by more than colour: legend words, a fixed stack order and 1px gaps. Marks paint with tone FG tokens or --gw-color-chart-1…6, never solids. Use a chart when the shape matters (a spike, a ranking); when one number matters, use a gw-stat; when exact values matter, use a table.

Interactive histogram

In the log explorer a column narrows the time range. Then the bars are buttons with an aria-label each: the labels carry the numbers (they replace the hidden table), so the root is a role="group", not an image. aria-pressed="true" marks the selected range with a fill and a brand bar on top; hover washes the column and focus rings it. Columns may get narrower than 24px, so the time-range picker next to the histogram stays the equivalent control.

Legend

The swatch takes the same modifiers as a segment: decision tones for status series, --series-1…6 for categories, and --hatch for idle time (the approval wait in a waterfall). A waterfall legend names its phases with the span tones: --neutral Gateway, --brand Resource. The words carry the meaning; an optional gw-legend__value gives the total.

Sparkline in a stat

An inline SVG polyline in currentColor with a non-scaling stroke: it stretches to any slot without thickening. Brand fg by default; tone it with a modifier. It is an image with its own label when it says something the number does not (the trend); aria-hidden when the text beside it already does.
