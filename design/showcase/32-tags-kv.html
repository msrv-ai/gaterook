Tags and key-value lists gw-tag gw-tag-list gw-kv

Tags hold values as tokens: allowlist entries (hosts, IPs, CIDRs, schemas), scopes, and the active filters of the log explorer. Literal values use the mono variant. When a tag can be removed, the remove control is a real 24 × 24 button named "Remove <value>". Do not use a tag for a status (badge) or for a choice the user toggles (checkbox, segmented control). Key-value lists show the facts of one object on a native <dl>: connection details, the request block of an event, the summary strip of a call. Do not use them for many objects with the same fields: that is a table.

Invalid and locked entries

An invalid entry takes the danger tone and a leading icon, and the field error names the value. A locked entry keeps its remove button focusable with aria-disabled="true", so the reason can be read out with it.

Long values

In a narrow column the label truncates with an ellipsis. The full value stays in the remove button's name and in title for the pointer; tab to the remove button and the label wraps in full.
