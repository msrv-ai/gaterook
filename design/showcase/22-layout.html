Page layout gw-page gw-section gw-toolbar gw-split gw-grid gw-divider

Arrangement only: these classes place cards, tables and forms inside gw-shell__main; they draw no surfaces of their own. gw-page is the only way to cap a width, so never set max-width or margin: 0 auto on page content.

Page widths

Default: up to 1440px of content with 32px gutters (16px below 640px), sections 32px apart. gw-page--narrow caps content at 880px for forms and settings read top to bottom. gw-page--full has no cap and fills main's height, so a gw-split inside it takes the remaining height (Approvals, Playground, Activity).

Section

A titled block of a page without a card around it: h2, an optional one-line description and actions on the right. Use a card instead when the block needs its own surface or footer.

Split

Master-detail with two panels that scroll on their own once the split has a height: inside gw-page--full it fills the rest of main, elsewhere set --gw-split-height (never a fixed height: below 960px the panels stack, the height is dropped and the page scrolls). Default 1 : 2 for queues (Approvals), --40 for lists with wide rows, --50 for input and output side by side (Playground).
