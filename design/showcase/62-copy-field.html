Copy field gw-copy-field

A read-only value the user takes somewhere else: an endpoint URL, a command for MCP Inspector, a token in the one moment it is visible. The "Copy" button reads the value through data-gw-copy-from, switches to "Copied" for 1.6 s and announces it. Do not use it for values the user edits (an input), for stored secrets (they are write-only: gw-secret) or for long snippets (a gw-code-block).
