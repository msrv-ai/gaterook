Table gw-table-wrap gw-table

A native <table> for dense, sortable lists of objects with the same fields: calls in Activity, connections, tokens, secrets. Screen readers get real rows and columns; sorting is a button inside th[aria-sort]; selection mirrors to tr[aria-selected]. The wrap is the scroller, so it is a named, focusable region. Do not use a table for one object's facts (a gw-kv list) or for a handful of rich items with actions (cards).

Sortable, with row selection

Click a header to sort; the icon follows aria-sort and the order is announced. The checkbox column uses data-gw-select-all and data-gw-select-row; a selected row gets the selected fill and a brand bar. Decisions are badges with icon and words; environments sit right after the connection name.

Interactive rows
